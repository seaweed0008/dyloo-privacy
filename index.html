privacy policy for dyloo (@dyl99bot)

last updated: 25 nov 2026

what this bot is

this bot moderates telegram groups. it deletes spam messages and keeps track of a whitelist so people you like never get banned.

what data it collects

user ids and first names

  • when an admin adds someone to the whitelist with /whitelist, the bot saves their telegram user id and first name in a file called whitelist.json
  • this is only so the bot knows who not to ban

messages

  • the bot reads messages in groups its added to, but only to check if they look like spam (links, floods, duplicates)
  • it does not save your messages. once it checks a message its gone, it doesnt store the text anywhere

strike counts

  • if someone who isnt whitelisted sends spam, the bot counts a strike
  • strikes are only kept in memory while the bot is running. if the bot restarts, strikes reset to zero

what it does with the data

  • the whitelist is only used to stop the bot from banning people you like
  • strike counts are only used to decide when someone has spammed 3 times and should be banned
  • thats it. the bot doesnt use your data for anything else

what it does NOT do

  • it does not sell your data to anyone
  • it does not share your data with anyone outside the group
  • it does not track you outside of groups its added to
  • it does not read your private messages or dms
  • it does not store your messages

where data is stored

  • the whitelist is stored in a file on the server where the bot runs
  • strikes are stored in memory only, they disappear when the bot restarts
  • no data is sent to any third party services

your rights

  • if youre on the whitelist and want to be removed, ask an admin to use /unwhitelist on one of your messages
  • if you want to know what data the bot has about you, ask an admin
  • if you leave the group, the bot doesnt keep tracking you

changes to this policy

if this policy changes, the new version will be posted here. check back every now and then.

contact

if you have questions about this policy or the bot, message @dyl99bot on telegram.
